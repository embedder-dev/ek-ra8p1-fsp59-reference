# Scratch block snapshots

Before the MRAM test, the scratch block `0x0207F800–0x0207FFFF` held 1,181 nonblank bytes of data left there by an earlier image, from before this validation. Snapshots of that pre-test content are omitted from this repository, because the data isn't ours to publish. Its SHA-256 and nonblank byte count are still recorded in the JSON evidence, for example [`mram-before.json`](mram-before.json).

The blank snapshots and the test pattern (`mram-pattern-scratch.bin`) are included.
